# easyAI

## Overview
A comprehensive educational platform designed specifically for SPPU (Savitribai Phule Pune University) engineering students pursuing SE Artificial Intelligence & Data Science (2024 pattern). This website serves as a one-stop resource for academic success.

## Purpose
The easyAI platform provides:
- **Subject-wise Syllabus**: Complete curriculum coverage for the 2024 pattern
- **Previous Years' Questions**: Last five years' SPPU examination questions organized by units
- **Comprehensive Notes**: Two types of study materials:
  - Simple notes for quick understanding
  - Detailed notes for thorough exam preparation
- **User-friendly Interface**: Easy navigation and organized content structure

## Features
- 📚 Subject-wise organized content
- 📝 Unit-wise question papers from last 5 years
- 📖 Dual-format notes (simple & detailed)
- 🎯 SPPU 2024 pattern specific
- 🔍 Easy search and navigation
- 📱 Responsive design for all devices
