# Academic Data Directory

This directory contains all academic content for SPPU SE AI & DS students (2024 pattern).

## Structure

### syllabus/
- Complete subject-wise syllabus documents
- Unit-wise breakdown of topics
- Course objectives and outcomes

### questions/
- **year_2024/**: Latest question papers
- **year_2023/**: 2023 examination papers  
- **year_2022/**: 2022 examination papers
- **year_2021/**: 2021 examination papers
- **year_2020/**: 2020 examination papers
- Organized by subjects and units

### notes/
- **simple/**: Quick reference notes for revision
- **detailed/**: Comprehensive notes for exam preparation
- Subject-wise organization
- Unit-wise classification

## Content Guidelines

- All content should be SPPU specific
- Follow 2024 pattern curriculum
- Include unit-wise organization
- Maintain consistent file naming
- Add metadata for easy searching

## File Formats

- PDFs for question papers and official documents
- Markdown files for notes and summaries
- Images for diagrams and flowcharts

## Contributing

When adding new content:
1. Verify it's SPPU 2024 pattern specific
2. Place in appropriate directory
3. Use consistent naming convention
4. Update relevant index files
