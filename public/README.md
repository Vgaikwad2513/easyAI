# Public Assets Directory

This directory contains all static assets and publicly accessible files for the easyAI website.

## Structure

### images/
- **logos/**: easyAI logo variants and branding
- **icons/**: Subject icons and UI elements
- **screenshots/**: Website screenshots and previews
- **diagrams/**: Educational diagrams and flowcharts
- **backgrounds/**: Hero images and background assets

### documents/
- **pdfs/**: Downloadable PDF resources
- **templates/**: Document templates for students
- **forms/**: Printable forms and checklists

### styles/
- **fonts/**: Custom web fonts
- **css/**: Additional stylesheets

### js/
- **libs/**: Third-party JavaScript libraries
- **plugins/**: Custom plugins and extensions

## File Organization Guidelines

- Use descriptive filenames
- Keep file sizes optimized for web
- Use appropriate image formats (WebP, PNG, SVG)
- Maintain consistent naming conventions
- Include alt text for accessibility

## Supported Formats

### Images
- **SVG**: Icons and simple graphics
- **PNG**: Screenshots and graphics with transparency
- **JPG**: Photos and complex images
- **WebP**: Modern web-optimized format

### Documents
- **PDF**: Question papers, syllabi, notes
- **DOCX**: Editable templates
- **TXT**: Plain text files

## Optimization

- Images should be compressed for web use
- Use responsive image techniques
- Implement lazy loading where applicable
- Consider CDN for large files

## Usage

All files in this directory are served statically and can be referenced directly in the web application using relative paths.
