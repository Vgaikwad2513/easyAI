# Source Code Directory

This directory contains the source code for the easyAI website.

## Structure

- **components/**: React/Vue components for the website
- **pages/**: Website pages and routing
- **styles/**: CSS/SCSS stylesheets
- **utils/**: Utility functions and helper modules

## Getting Started

1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Build for production: `npm run build`

## Technology Stack

- Frontend Framework: React/Vue.js
- Styling: CSS3/SCSS
- Build Tool: Vite/Webpack
- State Management: Context API/Vuex
