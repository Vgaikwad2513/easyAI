🧠

AI: Intelligent Agents

  • Agent = perceives through sensors; acts via actuators
  • PEAS: Performance, Environment, Actuators, Sensors
  • Agent types: reflex, model-based, goal-based, utility-based
  • Environments: observable, deterministic, episodic, static, discrete
📈

ML: Linear Regression

  • Hypothesis: y = w x + b
  • Loss: MSE; Optimization: Gradient Descent
  • Regularization: L1 (Lasso), L2 (Ridge)
  • Metrics: MAE, RMSE, R²
🗃️

DS: Data Wrangling

  • Handle missing: drop, mean/median, model-based
  • Encoding: One-Hot, Label, Target
  • Scaling: Standard, Min-Max, Robust
  • Pipelines: fit/transform workflow
