SPPU SE AI & Data Science Syllabus (2024 Pattern)

Course Overview

This page contains the complete syllabus for Second Year Engineering (SE) students pursuing Artificial Intelligence & Data Science under the 2024 pattern as prescribed by Savitribai Phule Pune University (SPPU).

Artificial Intelligence

Subject Code: AI2101

Credits: 4

Units:

  • Unit 1: Introduction to AI
  • Unit 2: Problem Solving & Search
  • Unit 3: Knowledge Representation
  • Unit 4: Machine Learning Basics
  • Unit 5: Expert Systems
  • Unit 6: AI Applications

Machine Learning

Subject Code: ML2102

Credits: 4

Units:

  • Unit 1: ML Fundamentals
  • Unit 2: Supervised Learning
  • Unit 3: Unsupervised Learning
  • Unit 4: Regression Analysis
  • Unit 5: Classification
  • Unit 6: Model Evaluation

Data Science Fundamentals

Subject Code: DS2103

Credits: 3

Units:

  • Unit 1: Data Science Introduction
  • Unit 2: Data Collection & Processing
  • Unit 3: Data Visualization
  • Unit 4: Statistical Analysis
  • Unit 5: Data Mining
  • Unit 6: Big Data Concepts

Python Programming

Subject Code: PY2104

Credits: 4

Units:

  • Unit 1: Python Basics
  • Unit 2: Data Structures
  • Unit 3: Object Oriented Programming
  • Unit 4: File Handling
  • Unit 5: Libraries (NumPy, Pandas)
  • Unit 6: Web Development

Database Management Systems

Subject Code: DB2105

Credits: 3

Units:

  • Unit 1: Database Fundamentals
  • Unit 2: ER Modeling
  • Unit 3: Relational Model
  • Unit 4: SQL
  • Unit 5: Normalization
  • Unit 6: Transaction Management

Statistical Methods

Subject Code: ST2106

Credits: 3

Units:

  • Unit 1: Descriptive Statistics
  • Unit 2: Probability Theory
  • Unit 3: Distributions
  • Unit 4: Hypothesis Testing
  • Unit 5: Regression & Correlation
  • Unit 6: ANOVA

Important Notes

  • This syllabus is based on SPPU's 2024 pattern for SE AI & Data Science
  • Each subject includes both theory and practical components
  • Regular updates will be posted as per university notifications
  • Students should refer to official SPPU documents for complete details
  • Laboratory practicals and assignments are integral parts of each subject
